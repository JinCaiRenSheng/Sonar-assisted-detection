# ShipSolver v1.6.0 三端响应式版

## 项目简介

ShipSolver 是一款用于《战舰》类游戏的离线推理辅助工具。它根据玩家录入的“船 / 空”结果、船只配置和已确认船块，枚举合法候选位置并计算推荐探测点。

本项目为纯前端单页应用，无服务器、无第三方依赖。所有数据默认保存在浏览器 `localStorage` 中，可离线运行，也可导入或导出存档。

## 文件结构

```text
ShipSolver_v1.6.0_Responsive/
├── index.html
├── README.md
└── CHANGELOG.md
```

直接双击 `index.html` 即可运行。

## v1.6.0 核心升级

### 1. 真正的三端响应式布局

- PC：棋盘在左，分析和探测面板在右。
- 平板：棋盘在上，面板自动换到下方。
- 手机：顶部紧凑控制栏、横向图例、可折叠面板、底部探测选择菜单。
- 手机横屏：自动进入紧凑横向布局。

### 2. 动态棋盘尺寸

棋盘格尺寸不再固定为单一像素值，而是根据以下条件动态计算：

- 当前视口宽高；
- 棋盘行列数；
- PC、平板或手机可用空间；
- 横屏或竖屏状态。

窗口大小变化、平板分屏或手机旋转后，棋盘会自动重新计算并重绘。

### 3. 缩放与全屏

顶部工具栏提供：

- `－`：缩小棋盘；
- `自动`：恢复自动适配；
- `＋`：放大棋盘；
- `⛶`：进入或退出浏览器全屏。

### 4. 核心推理

- 自动识别连通船块；
- 对长度不小于 2 的船块执行侧面逻辑锁定；
- 对已完成船块执行 8 方向锁定；
- 枚举剩余船只的合法横向和纵向位置；
- 禁止对角相邻冲突；
- 根据候选覆盖度与已探空边缘计算推荐点；
- 标记所有候选共同覆盖的“必然船格”；
- 推荐 3×3 大探测区域。

### 5. 操作与资源

- 左键：标记船，再次点击取消；
- 右键：标记空，再次点击取消；
- Shift + 左键：选择整艘船；
- 确认整船：将选中船块加入完成判定；
- 小探测：手机端使用底部菜单选择“船 / 空 / 取消”；
- 大探测：先暂存多个结果，再统一确认；
- 支持大探测次数、小探测次数和声呐币。

### 6. 存档和日志

- 自动保存当前工作区；
- 命名保存与读取；
- 删除单个存档；
- 导出全部存档；
- 导入 JSON 存档；
- 导出反馈日志，包含版本、棋盘状态、操作日志、浏览器信息和视口尺寸。

## 使用方法

1. 解压 ZIP。
2. 双击 `index.html`。
3. 设置棋盘大小与船只配置。
4. 左键录入船，右键录入空。
5. 查看“探测建议”和“大探测区域”。
6. 需要锁定整船时，按住 Shift 点击船格，再点击“确认整船”。

## 快捷键

- `Ctrl + Z`：撤销；
- `Ctrl + Y`：重做；
- `Shift + 左键`：选择整艘船。

## 浏览器兼容性

建议使用近期版本：

- Chrome；
- Edge；
- Firefox；
- Safari。

全屏与振动反馈受浏览器权限和设备支持影响；不支持时不会影响核心功能。

## 数据说明

默认本地存储键：

```text
shipsolver_saves
shipsolver_autosave_v1_6_0
```

清除浏览器站点数据会删除本地存档，因此重要存档应及时导出。

## 已知限制

- 当前候选枚举以“单艘船合法位置覆盖”为主，不是完整全局组合搜索；大棋盘和复杂局面下推荐属于启发式结果。
- 历史先验开关已保留，但当前版本未把跨存档概率矩阵叠加进推荐分数。
- 使用 `file://` 直接打开时，不同浏览器对本地存储和全屏权限的策略可能略有差异。
