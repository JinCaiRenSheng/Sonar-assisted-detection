# ShipSolver v1.6.4 桌面稳定版

## 项目定位

ShipSolver 是用于《战舰》类游戏的离线推理辅助工具。
本版本基于稳定桌面架构，重点优化：

- 判定逻辑完善
- 桌面网页 UI 正确性
- 推理结果稳定性

纯前端单文件运行，无服务器、无第三方依赖。

## 本版本核心调整

### 1. 判定逻辑

保留并强化：

- 船块识别
- 已知船/空约束
- 船只合法位置枚举
- 对角不可相邻规则
- 船块侧面锁定
- 完成船 8 方向锁定
- 必然船格推导
- 推荐探测点评分
- 3×3 大探测区域计算

### 2. UI

采用桌面网页布局：

- 左侧棋盘区域
- 右侧状态、推荐、探测操作区域
- 所有功能按钮直接展示

移除：

- 手机布局
- 平板布局
- 触摸长按逻辑
- 移动端折叠菜单

电脑端无需隐藏功能。

## 使用

1. 双击 index.html。
2. 设置棋盘大小和船只配置。
3. 左键标记船，右键标记空。
4. 查看推荐探测位置。
5. Shift+左键选择船块后确认整船。

## 快捷键

- Ctrl+Z 撤销
- Ctrl+Y 重做
- Shift+左键 选择整船
