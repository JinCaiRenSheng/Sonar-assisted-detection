# ShipSolver

战舰游戏（Ships / Battleship）推理辅助工具：单文件、离线、双击即用。

## 使用

下载 [index.html](index.html)，用 Chrome / Edge 打开即可，无需安装、无需联网。

## 功能

- 多策略推理：覆盖计数、邻域期望、空密度感知、历史先验
- 推荐探测点（前 3）与大探测推荐
- 必然船 / 必然空格自动推导、高置信格提示
- 概率热力图（蓝→红 = 低→高）
- 存档：分期管理、自动保存、导出 / 导入
- 电脑、平板、手机自适应；手机支持点按标船、长按标空
