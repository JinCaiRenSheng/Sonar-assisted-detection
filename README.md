# ShipSolver v1.1.0 Stable

单文件舰船探测推算工具。双击 `index.html`，使用 Chrome 或 Edge 打开即可。

## 版本定位

v1.1.0 在 v1.0.0 Stable 的基础上加入追击/巡航策略、命中簇管理、候选差异格和更严格的自动确认规则。仍保持单 HTML、离线运行、旧存档兼容。

## 核心状态

程序只长期保存事实：

- 未知
- 船
- 空
- 信息来源：普通录入、大探测、自动推断、小探确认

以下内容全部由当前盘面重新计算，不直接作为事实保存：

- 已完成船只
- 锁定区域
- 剩余船型
- 候选船位
- 推荐分数
- 大探测区域

## 两种推荐模式

### 追击模式

只要存在尚未完成的命中船体，系统优先处理该命中簇。

命中簇按以下原则排序：

1. 已命中的船格越多，优先级越高；
2. 完整候选船位越少，优先级越高；
3. 越接近确定长度，优先级越高。

追击模式不会被历史存档权重带到无关区域。

### 巡航模式

没有未完成命中簇时，根据全部剩余船型的合法摆放位置生成全局热力。

历史存档只以 1% 的极弱权重参与巡航排序，不参与必然判断，也不会覆盖当前盘面事实。

## 候选差异格

橙色边框表示“候选差异格”。

例如同一命中船体可能横向，也可能纵向时，系统优先推荐能够区分这两类方案的位置，而不是远处单纯覆盖率最高的位置。

推荐面板会显示：

- 当前策略模式；
- 目标命中簇；
- 完整候选数量；
- 关键判别格；
- 该格能将候选分为多少种“有船”和“无船”；
- 首选大探测区域及推荐原因。

## 自动确认整船

只有同时满足以下条件时，系统才自动确认：

1. 命中簇只剩一个完整合法摆放方案；
2. 该方案内所有格子都已经记录为船；
3. 对应长度仍有未完成名额；
4. 不与已确认船和锁定区域冲突。

不会仅因为“似乎无法继续延伸”就自动确认。

## 基本操作

- 未知格左键：记录为船。
- 未知格右键：记录为空。
- 点击已知船格：选择整段船体。
- 点击“确认整船”：手动确认当前船体。
- Ctrl+左键或 Ctrl+右键：取消已有标记。
- 锁定格不能直接编辑，需要先修改产生锁定的船体。

## 大探测

1. 点击“开始本次大探测”；
2. 在棋盘连续录入结果；
3. 左键记录船，右键记录空；
4. 再次点击本次已录入的同一格，可以取消该格；
5. “撤销”只撤销本次大探测最后一格；
6. 点击“确认本次”后，整批结果写入历史；
7. 点击“取消本次”恢复开始前状态。

推荐区域会随本次录入即时变化。

## 小探确认

开启“小探确认”后，点击已经记录的船或空，表示该格已经在游戏中使用单点方式确认。

大探测规划会减少重复覆盖这些格，但不会改变其船/空事实。

## 显示说明

- 红色：已知船；
- 黑色：已知空；
- 灰色斜纹和 ×：锁定区域；
- 黄色边框：一般可能区域；
- 橙色边框：候选差异格；
- 绿色边框：当前全部合法方案中必然为船；
- 红黄蓝区域：大探测推荐区域；
- 右下角 ✓：已经小探确认。

## 存档

- 保存当前：覆盖当前命名存档；
- 另存为：创建新存档；
- 支持导入/导出单个 JSON；
- 支持导出全部命名存档；
- 支持自动恢复工作区；
- 兼容 v1.0.0 与近期 32.x 稳定版自动保存。
