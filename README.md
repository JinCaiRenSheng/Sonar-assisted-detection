# ShipSolver

战舰游戏（Ships / Battleship）推理辅助工具：单文件、离线、双击即用。

## 使用

下载 [index.html](index.html)，用 Chrome / Edge 打开即可，无需安装、无需联网。

## 使用前提（断网玩法）

本工具用于**断网对局**的战舰游戏辅助，只提高探测效率，不代玩。

安卓双机操作步骤：

1. 一台手机开热点，另一台（游戏机）连上该热点；
2. 游戏机打开游戏后，**关闭热点机的数据连接**（游戏机仍连着热点 WiFi，但已断外网）；
3. 游戏内探测，把结果录入本工具；
4. 一次操作完成后，**划掉游戏进程**，打开热点机的数据连接，重进游戏；
5. 重复以上步骤，逐轮推进。

## 功能

- 多策略推理：覆盖计数、邻域期望、空密度感知、历史先验
- 推荐探测点（前 3）与大探测推荐
- 必然船 / 必然空格自动推导、高置信格提示
- 概率热力图（蓝→红 = 低→高）
- 存档：分期管理、自动保存、导出 / 导入
- 电脑、平板、手机自适应；手机支持点按标船、长按标空
