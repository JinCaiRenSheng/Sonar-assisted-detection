# ShipSolver v2.4.6 功能完整手册

> 战舰游戏（Ships / Battleship）推理辅助工具 —— 单文件纯前端，双击即用，无需联网。
> 本文件既是开发记录，也是**全部功能的完整说明**。

## 〇、七条至高规则（开发准则）

1. **大探测 = 录入事实，不是预测** —— 大探测只在目标区域录入已确认的事实（船/空），不做猜测。
2. **大探测只推荐单点，不探测九格** —— 推荐的是最高价值的一个格子，让玩家自己判断，绝不自动掀开一片。
3. **保持保守，不武断推断** —— 引擎只给出"能严格证明"的结论，宁可少说，不说错。
4. **推荐前 3，辅助决策** —— 只展示分数最高的 3 个推荐格，有效候选不足 3 个时不硬凑，供玩家参考，不替玩家做决定。
5. **存档绝不丢数据** —— 任何版本迁移、导入合并，都不能让玩家已有的进度丢失。
6. **日志精炼分类，可反查** —— 操作日志和推理日志分开记录，格式统一，方便回溯。
7. **适时询问，存在误解直接问，不猜** —— 与玩家的交互以理解为先。

## 一、推理引擎（核心大脑）

### 推理流水线
每次棋盘变化后按顺序执行：

```
blocks() ──► locksAndProgress() ──► enumerate() ──► scoreCells() ──► findForced() ──► autoConfirm() ──► 强制空格 ──► 碎片合并 ──► highConf()
```

| 步骤 | 作用 |
|------|------|
| `blocks()` | 生成所有可用格（排除空/已确认船/锁定格） |
| `locksAndProgress()` | 计算每艘船已放置进度、锁定判断、已用计数 |
| `enumerate()` | 枚举所有船型在所有位置的合法摆放方案 |
| `scoreCells()` | 按多策略给每个候选格打分（见下表） |
| `findForced()` | 找出"必是船"或"必是空"的强结论格 |
| `autoConfirm()` | 自动确认可 100% 判定的格（可开关） |
| 强制空格 | 没有任何合法方案覆盖的未知格 = 必然为空，自动标空（100% 逻辑结论） |
| 碎片合并 | 只有一种剩余船型能容纳且方案唯一时，才强制延伸碎片 |
| `highConf()` | 高置信格：在 >60% 的可行方案中都是船的格子，给出概率提示 |

### 多策略评分表
| 策略 | 小盘（≤25 格）权重 | 大盘权重 |
|------|------|------|
| 方案覆盖度 | ×2.4 | ×1.3（基础分，命中优先） |
| 邻域期望 | ×0.4 | ×0.3（大探测点一格、结果位置不定 → 选周边3x3期望命中最高的中心格） |
| 空密度感知 | 关闭 | −空密度×1.2×edgeFactor（已探空密集区降权，推荐向未探/空少区域倾斜） |
| 历史先验 | 默认开启 | 相对密度倍数加分（历史船分布高于均值越多加分越多） |
| 邻近碎片加成 | ×2.5 | 加分 |
| 平衡增益 | 仅微调（覆盖×0.5+平衡×2） | 仅微调 |

> 评分目标 = **把所有的船探出来**：覆盖度（船概率）优先，信息平衡只作微调，不再追求
> "探索价值点"而牺牲命中机会。

### 自动确认（保守原则）
- 只确认**逻辑上 100% 确定**的格子（例如：某格在全部合法方案里都是船/都是空）。
- **强制空格**：某未知格不被任何剩余船型的合法方案覆盖时，该格必然为空，自动标空（v2.2 新增）。
- 自动确认 / 碎片合并 / 强制空格每轮变化后**全部重算**，保证后续推导使用最新方案，不漏判。
- **方案枚举排除已确认船**（v2.2.1）：已确认完成的船不会再被生成为候选方案，避免污染候选数与"必然船"判定。
- **必然船色彩**：多方案公共格（必是船）保留绿色描边并列出，不被自动确认吞掉（v2.2.1 修复）。
- **锁定格仅提示**（v2.2.3 回退 v2.2.2 的自动标空）：锁定格是逻辑必空，只保留条纹提示、**不写入盘面**；游戏大探测可能重探这些格并给出结果，玩家仍可正常录入（引擎会校验冲突）。
- **完成盘面补全**（v2.2.2）：全部船确认后，剩余未知格自动标空，盘面无残留未知。
- 碎片合并仅在**唯一一种船型能容纳、且摆放方案唯一**时才补格，绝不武断。
- 高置信格只提示概率，不自动确认（>60% 方案为船）。

### 历史先验（利用历史盘数据推断）
- **数据来源**：所有存档中**同尺寸**的历史盘面（v2.2.5 放宽：不再要求配置完全一致，船的位置习惯主要与棋盘布局相关）。
- **启用条件**：至少 2 盘同尺寸历史盘（v2.2.5 新增），否则自动停用。
- **加分方式**（v2.2.5 修复）：旧版按"密度×权重"加分（实测仅 0.1 分，形同虚设）；现改为**相对密度倍数**——历史船密度高于均值越多加分越多，实测 10x10 基于 3 盘时可产生约 4 分影响，是合理的软信号。
- **默认开启**（v2.2.5）：设置面板显示"基于 N 盘同尺寸历史盘"。
- **数据积累**：每盘完成自动归档后，同尺寸历史盘持续增加，先验会越来越可靠（配合 3 个月存档目标）。

### 安全约束
- 不破坏已确认的船格、锁定格。
- 不产生船体对角线接触（对角格子不能放船）。
- 已完成的船不会继续放多余格子。

## 二、交互操作

| 操作 | 效果 |
|------|------|
| 左键点击格子 | 标记为**船**（⬛） |
| 右键点击格子 | 标记为**空**（水，✔️） |
| Shift + 点击 | 选中格子（用于给船格做"确认"等操作） |
| 右键点击已标船格 | 确认该格为船（锁定） |
| 点击"确认整船"按钮 | 一键确认当前选中的整艘船 |
| Ctrl + Z | 撤销上一步 |
| Ctrl + Shift + R | 重做 |

### 格子状态与显示
- **未知**：空白（可操作）
- **空**：水花标记（✔️ 或水滴）
- **船**：深色方块（⬛）
- **确认船**：锁定样式（颜色不同，且不可再修改）
- **锁定格**：不显示推荐高亮
- **推荐格**：3 个，带分数角标和颜色区分（第 1 红、第 2 橙、第 3 黄）

### 保护机制（误操作防护）
1. 游戏完成（全部船确认）后，棋盘锁定不可操作。
2. 已锁定的格不可修改。
3. 已确认的船格不可修改。
4. 对角格子不能点船。
5. 孤儿格（不合理的孤立船格）标记时给出原因警告。

## 三、大探测 / 小探测

### 大探测（v2.1 重构后的机制）
- **本质**：在目标区域录入事实，不是预测，也不自动探测九格。
- **概率热力图**（v2.2 新增，v2.2.1 改常态显示，v2.2.2 改色）：棋盘**常态**显示相对船概率渐变（**蓝→橙金** = 低→高，避开船格的红色系）；高概率格直接显示百分比数字；船格带白色内描边；悬停可看精确概率，可在设置中关闭。
- **探过/没探过区分**（v2.2.1）：大探测会话中，已暂存的格子用**实色**覆盖热力图（绿=船、暗=空），一眼分清哪些点已录入、哪些还没有。
- **操作**：
  - 左键 = 船（录入"这里是船"的事实）
  - 右键 = 空（录入"这里是空"的事实）
  - 直接录入，**无循环切换**
- **推荐**：只推荐最高价值的**单点**，由玩家自己判断后录入。
- **不消耗资源**：确认大探测结果**不消耗** `bigDetect` 次数。
- 确认后：`consecutiveMisses`（连续未命中）归零，记录 `bigHistory`，日志含船/空明细。

### 小探测
- **已移除**（v2.1 起）。原小探测的九格掀开功能已废弃，避免与"保守原则"冲突。

## 四、存档系统

### 存储位置
- 浏览器 `localStorage`
- 主存档键：`shipsolver_saves`
- 自动存档键：`shipsolver_autosave_v2_0_0`（键名保持不变，避免丢进度）

### 分期槽结构
- 存档按 **"期"（Period）** 分槽管理，如「第 1 期」「第 2 期」…
- 结构：`{ _periods: {...}, _currentPeriod: '第 1 期' }`
- 每个期独立保存棋盘、船配置、确认状态、工具资源、统计等完整快照。

### 功能表
| 功能 | 说明 |
|------|------|
| 存档 | 把当前状态存入当前期 |
| 读档 | 从任意期恢复，读取后自动切到该存档所在期 |
| 列出所有期存档 | 打开存读档弹窗即一次性显示**全部期**的存档（📌=当前期，🕘=往期），无需手动切期 |
| 期下拉框 | 在存/读档弹窗中切换保存目标期 |
| 新建期 | 创建新的存档槽 |
| 删除期 | 删除指定存档槽 |
| 期合并 | 在设置弹窗选来源期+目标期，一键把来源期全部存档并入目标期（重名跳过不覆盖，来源期保留） |
| 【当前】标记 | 当前期标题和该期下每个存档均标绿显示【当前】；当前正在使用的存档另标【当前盘】 |
| 自动保存 | 自动保存，弹窗显示上次自动保存时间 |
| 导入 JSON | 合并导入，绝不覆盖重名项 |
| 导出 JSON | 完整导出备份（含所有期） |

### 导入策略（不丢数据）
- **完整备份**（含 `_periods`）：合并所有期，重名的期跳过不覆盖。
- **单存档**：并入当期，重名跳过不覆盖。
- 导入后刷新期下拉框。

### 跨版本迁移
- `getSaves()` 自动识别并迁移三种旧格式：
  1. 新版 `_periods` 结构
  2. 扁平旧格式
  3. `{version, saves}` 包装格式
- `restore` 兼容缺失字段：旧存档缺的新字段用默认值补齐。

## 五、日志系统

### 分类
- **操作日志（actions）**：玩家每一步操作（标记船/空、确认、撤销等）。
- **推理日志（reasoning）**：引擎的推理过程（发现了什么、确认了什么、为什么）。

### 操作日志格式
```
[操作] 说明 | 位置 (行,列) | 棋盘快照
```
- **预测与实际对应（结构化）**（v2.2.4）：每条操作日志带 `rec` 字段
  `{r, c, followed, hit}`（推荐格坐标、是否被探、实际是否命中船），
  可直接用于统计推荐命中率与概率校准，不再依赖文本解析。
- **每局时长**（v2.2.4）：反馈导出 summary 含 `durationSec`（本局用时）。
- **操作时间**：每步操作与推理均带 ISO 完整时间戳 `time`，供回溯顺序与节奏。

### 推理日志格式
```
[推理] 结论类型 | 格子位置 | 依据（哪种策略/为什么）
```

### 高置信格
- 引擎找到 >60% 方案为船的格子时，在推理日志中提示，并在棋盘上给出概率角标。

## 六、推荐统计

- 记录推荐 → 玩家行为 → 结果的完整链路：
  - `recGiven`：给出的推荐次数
  - `recFollowed`：玩家采纳推荐的次数（推荐格被实际探测即计为采纳，v2.2 修复：此前只有推荐格为船才计数）
  - `recHit`：采纳后命中的次数
- 用于评估推荐质量，可按需微调评分权重。

## 九、手机/平板双排版（v2.3.0）

- **同一份文件，两套排版**：`index.html` 既是电脑版也是手机/平板版，打开时自动判断。
- 切换规则：
  - 触屏设备（手机、平板）→ 手机排版，无论横屏竖屏；
  - 电脑：宽度 > 820px 用电脑排版；窗口拖窄到 ≤ 820px 自动切手机排版；
  - 设置里可强制：自动 / 强制电脑排版 / 强制手机排版。
- 两套排版互不影响：手机样式全部挂在"手机模式"标记下生效，电脑样式一字未动。
- 手机排版（窄屏 ≤ 820px）：单栏——标题 → 操作按钮两列 → 棋盘 → 图例（默认收起）→
  三个信息面板（探测建议默认展开，进度/操作默认收起）。
- 平板宽屏（> 820px 触屏）：双栏——棋盘在左、信息在右，操作仍为触控。
- 触控操作：
  - 点一下格子 = 标船，再点 = 取消；
  - 长按约 0.5 秒 = 标空，再长按 = 取消（长按时轻微震动）；
  - 顶栏「标船/标空」切换按钮应对复杂局面；
  - 大探测：点 = 暂存船，长按 = 暂存空；
  - 棋盘区域已禁用系统长按菜单（长按不弹复制），输入框不受影响。
- 手机上推荐 1/2/3 标号直接画在棋盘格子上，不看面板也知道往哪探。
- 弹窗（存读档 / 设置 / 帮助）在手机上全屏显示。
- 存档：手机与电脑的浏览器存档互不相通，跨设备用「导出全部 → 导入」搬运。

### v2.3.1 实测修复（2026-08-04 实机反馈）

- **长按防复制加固**：触屏交互改为由触摸事件直接接管（按住 0.5 秒=标空、轻点=标船），
  棋盘上的触摸开始事件被拦截，夸克等国产浏览器不再弹出"复制/搜索"长按菜单；
  电脑鼠标操作完全不受影响。
- **常用功能常驻**：手机/平板棋盘下方新增快捷操作条（撤销、确认整船、开始/确认/取消大探测），
  不再藏在折叠面板里；禁用状态与面板按钮同步。
- **格子字号调小**：手机上坐标号 7px、船●空×标记 11px，避免小格子内容显大拥挤。
- **导入修复**：导入按钮改为系统原生文件选择（更多浏览器可靠）；解析前自动去掉 BOM；
  失败时提示具体原因；选完文件可再次选择同一文件。
- **反馈收集**：手机上点「反馈」先弹窗，可一键复制全文（粘贴发给开发者）或下载文件，
  解决手机端反馈"怎么截取、怎么发送"的问题。
- **小窗优化**：矮窗口（浏览器小窗/分屏）自动隐藏标题，棋盘按高度重算、尽量放大。
- **流畅度**：点击后棋盘先画、文字面板下一帧再更新；自动保存改为 0.8 秒合并一次，
  减少手机端反复写盘造成的卡顿。

### v2.3.2 手势修复（2026-08-04 三款手机浏览器实测反馈）

- **滑动/缩放恢复正常**：不再拦截棋盘上的"触摸开始"事件（此前为防长按复制拦截了它，
  导致从棋盘区域开始的滑动/缩放"时而有效、时而没反应"）。现在触摸手势完全交给浏览器，
  页面滚动与双指缩放恢复流畅。
- **长按更精确**：长按只在"按住不动约 0.5 秒"时触发标空，手指一动（滑动/缩放）立即取消，
  不会误标空。
- **防重复**：短按后浏览器自动补发的点击、长按后系统弹出的菜单都被识别并忽略，
  不会出现"标了船又被取消"或"长按标空又被系统菜单取消"。
- **防复制兜底**：手机模式下自动清除棋盘区域的意外文本选中，阻止长按弹"复制"菜单；
  输入框不受影响。个别浏览器（如夸克）若仍弹菜单，可用快捷操作条的「标船/标空」切换按钮，
  完全不依赖长按。
- **快捷条加切换按钮**：棋盘下方快捷操作条新增「●标船 / ×标空」切换按钮（高频操作常驻），
  与顶栏按钮状态同步。

### v2.3.3 桌面滚轮修复（2026-08-04）

- **网格区域滚轮恢复**：棋盘容器原有的"滚动拦截"设置会让鼠标在网格上滚轮时页面纹丝不动
  （容器没有内部滚动内容却吞掉滚轮事件）。已移除该设置，电脑上在棋盘上滚动鼠标
  即可正常滚动页面；手机触摸滚动不受影响。

### v2.3.4 大屏布局加宽（2026-08-04 电脑端 16.1 寸屏实测反馈）

- **大屏不再空**：页面可用宽度 1280 → 1600px，右侧信息栏 275 → 320px，
  棋盘上限 56 → 68px，10×10 棋盘在 2560 宽屏上约 495 → 962px，1080p 约 778px。
- 小屏（1366×768 等）按屏幕自动收缩，不溢出；手机/平板排版完全不受影响。

### v2.3.5/v2.3.6 棋盘四角快捷按钮（试验特性，2026-08-04）

- **利用菱形棋盘四角的空白三角区**：大屏/平板棋盘四角放 4 个快捷按钮——
  左上↶撤销、右上标船/标空切换、左下🔒确认整船、右下大探测（开始后变"✓确认"）。
- 显示条件：桌面始终显示；平板（宽≥601 且高≥501 的触屏，含竖屏 768×1024）显示；
  手机窄屏/横屏隐藏（空间不够，保持简洁）。
- 按钮贴在棋盘角上、不遮挡格子；与快捷操作条、顶栏按钮状态实时同步。
- 试验中：如四角利用率不高或遮挡观感不佳，可随时撤下。

### v2.3.7 四角按钮开关（2026-08-04 讨论定案）

- 设置里新增「启用棋盘快捷按钮（电脑/平板，四角）」开关，默认开启，选择会记住。
- 开启：电脑/平板显示四角快捷按钮，同时收起重复的原按钮
  （顶栏撤销、顶栏/快捷条标船标空、快捷条确认整船、开始大探测）；
  大探测的「取消」保留在面板与快捷条（四角管不了取消）。
- 关闭：四角按钮隐藏，原按钮全部恢复，界面回到传统布局。
- 手机不受该开关影响：手机不显示四角按钮，所有操作仍在快捷条与面板上。

### v2.3.8 平板小窗识别 + 手机四角快捷键（2026-08-04）

- **平板小窗不再变手机排版**：设备判断改用"屏幕物理尺寸"（而非窗口宽度）。
  平板分屏小窗时仍识别为平板：四角按钮始终显示、快捷条与折叠面板保留，
  布局随窗口宽度自适应单栏/双栏。手机（屏幕宽度 < 600）才按手机处理。
- **手机也加棋盘快捷键**：手机竖屏棋盘四角显示 4 个小号按钮
  （34px：↶撤销、船/空切换、🔒确认整船、探/✓大探测），与桌面/平板操作位置统一；
  手机横屏矮窗因空间不足仍隐藏。小棋盘（3×3 等）四角空间不足时自动隐藏。
- 四角按钮大小随视口自适应：宽 ≥600 用 44px，窄窗用 34px。
- 「启用棋盘快捷按钮」开关现在对手机同样生效（默认开）。

### v2.3.9 手机不做横屏适配（2026-08-04）

- 手机（含横屏）一律单栏竖屏样式，不再切双栏；双栏只给平板宽屏用。
- 手机横屏四角按钮保持隐藏（矮窗空间不足），布局简单一致。

### v2.4.0 手机四角固定 + 流畅度 + 日志存档增强（2026-08-04）

- **手机四角按钮固定在棋盘面板四角**：不再依赖棋盘三角区大小，任何手机尺寸
  （含 360 宽小屏）都稳定显示，与浏览器缩放无关。
- **滑动流畅**：重画棋盘只在窗口宽度变化时触发；手机/平板仅高度变化
  （浏览器地址栏收放）不再重画，消除滑动卡顿。
- **日志增强**：推理日志记录每次推理耗时（ms）；自动捕获页面运行时错误
  （js_error，反馈里直接可见）；日志保存条数放宽（操作 200 条 / 推理 100 条）。
- **存档增强**：删除存档前二次确认；检测到损坏存档自动备份到本地
  （含启动时自动保存损坏的情况），不再直接丢弃。
- **存读档界面优化**：期标题加大（13px 高亮色块，当前期绿色底），
  去掉每行重复的【当前】字样，只保留"当前盘"金色小徽章；信息行字号 10→11px。

### v2.4.1 状态颜色统一（2026-08-04）

- 存档状态颜色区分：完成=绿色、进行中=蓝色（原黄色与"当前盘"金色徽章撞色，已改）、
  当前盘=金色徽章、当前期标题=绿色底。
- 存读档弹窗底部说明、帮助文档同步更新，不再出现过时的【当前】描述。

### v2.4.2 卡顿可查 + 移动端渲染减负（2026-08-04 平板实机反馈）

- **移动端去掉毛玻璃模糊**（backdrop-filter）：平板/手机滚动与重绘性能大幅提升
  （此前的滚动卡顿主要来源之一）；电脑桌面保留原效果。
- **日志能"说出"卡顿**：
  - 推理耗时（已有）；
  - 新增：渲染棋盘耗时（≥30ms 才记）、自动保存写入耗时（≥20ms 才记）；
  - 新增：浏览器长任务监控（主线程卡顿 ≥50ms 自动记入推理日志，如"长任务 120ms"）。
  - 以上都会进入反馈导出，卡顿可直接定位到具体环节。

### v2.4.3 日志与导出命名完善（2026-08-04）

- **操作日志类型改中文全名**：标记船 / 标记空 / 取消标记 / 右键确认船 / 按钮确认船 /
  大探测确认 / 本局完成 / 页面错误（旧英文标识自动转换，含历史日志导出）。
- **导出文件命名完整**（带版本号与精确到秒的时间，便于区分多次导出）：
  - 反馈：`ShipSolver_反馈_v2.4.3_YYYYMMDD-HHMMSS.json`
  - 存档备份：`ShipSolver_存档备份_v2.4.3_YYYYMMDD-HHMMSS.json`

### v2.4.4 棋盘渲染提速（2026-08-04 反馈日志定位卡顿后）

- **增量渲染**：棋盘格子元素复用，只更新变化的部分（标记、高亮、热力），
  不再每次整块重建。实测连续点 10 次格子无一次慢渲染（<30ms），
  仅页面首次创建棋盘有一次性开销（真实平板可忽略）。
- **坐标号可开关**：设置里新增「显示格子坐标号」，默认开；看不清时可关闭
  （关闭后绘制更轻，字小也不怕）。
- **手机/平板阴影减轻**：船格、推荐格等描边阴影减细（1~2px），降低重绘成本，
  视觉更清爽；电脑桌面保留原样式。
- 推理计算保持原样（60~133ms，正常范围）；渲染提速后单次操作总耗时大幅下降。

### v2.4.5 日志存档升级（A+B 档，2026-08-04）

- **存储适配层（为 C 档预留接口）**：新增 StorageBackend 统一读写接口
  （get/set/remove，Promise 形式）。当前用 localStorage 实现；
  以后上 C 档换 IndexedDB 实现即可，业务代码不用改。
- **A 档·日志与存档分离**：
  - 日志独立存放（`shipsolver_logs_v1`），不再与存档挤一个保险柜；
  - 按"每次打开页面"分会话段，保留最近 5 段，段内操作日志上限 2000 条、推理 1000 条；
  - 关闭/切后台页面时立即落盘，减少日志丢失；
  - 存档里只带最近 10 条轻量日志（省空间），完整日志在独立存储里。
- **B 档·可回退 + 多槽自动保存**：
  - 撤销栈持久化（`shipsolver_undolog_v1`）：最近 30 步，重启后仍可 Ctrl+Z 回退；
  - 自动保存多槽（`shipsolver_autoslots_v1`）：每 0.8 秒的自动保存留下时间快照，
    保留最近 20 个，存读档弹窗显示"自动快照"列表，可一键恢复历史进度。
- 接口与数据键均带版本后缀，C 档迁移时数据可平滑对接。

### v2.4.6 滚动流畅度 + 设备识别（2026-08-04 平板实测反馈）

- **棋盘独立合成层**（will-change + contain）：滚动页面时棋盘整体走 GPU 合成，
  不再反复重绘，解决"滑动时卡"的问题；点格子本身已流畅（增量渲染生效）。
- **反馈记录设备屏幕尺寸**（screenW/screenH）：与窗口尺寸并列，
  以后导出的反馈可准确区分手机与平板（此前只记窗口大小导致误判）。
- **长按复制说明**：夸克等国产浏览器的长按菜单属于浏览器自身功能，
  网页能做的标准拦截（禁用选中、拦截菜单、清除选中）已全部启用；
  个别浏览器仍弹出时，长按标空照常生效，也可直接用「标船/标空」切换按钮。
