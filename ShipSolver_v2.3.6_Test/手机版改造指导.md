## 一、目标（一句话）

同一个 index.html：按设备自动切换"电脑排版"和"手机排版"两套界面，两套互不影响。
手机上用手指操作，电脑上用鼠标操作，各自保持原样。
**平板也算手机排版**：平板和手机一样是触屏操作（没有右键），只是屏幕宽，
布局自动变成"棋盘在左、信息在右"的双栏形态，不浪费宽度。

---

## 二、历史教训（为什么不能像以前那样做）

- 以前的 v1.6.0 做法是"屏幕一变窄，就逐个改写页面组件的样式"（专业说法：全局媒体查询覆盖）。
  结果是：电脑上把窗口拖小一点，页面也跟着变，用着难受；改手机样式时还容易误伤电脑样式，出现排版错乱。
- 本次对策（三条）：
  1. 电脑排版这套样式**一字不改**，只负责电脑模式；
  2. 手机排版单独一套，全部挂在"手机模式"的标记下，只在手机模式生效，不碰电脑样式；
  3. 加"自动 / 强制电脑排版 / 强制手机排版"三选一开关：电脑上想锁死电脑排版，窗口怎么拖都不变。

---

## 三、切换机制

- 自动判断（两把尺子：宽度 + 是否有鼠标）：
  - 触屏设备（手机、平板）：一律手机排版，无论横屏竖屏；
  - 电脑（有鼠标）：宽度 > 820px 用电脑排版，窗口拖窄到 ≤ 820px 会自动切手机排版；
  - 手机排版的形态：窄屏（≤ 820px）单栏，宽屏（> 820px，如平板横屏）双栏。
- 这样手机和平板永远走手机排版（触控），只有电脑的宽窗口才走电脑排版。
- 防抖：宽度在临界点附近来回变化时，等一小会儿再切换，不会闪跳。
- 手动开关（放在设置里，默认"自动"）：自动 / 强制电脑排版 / 强制手机排版。
- 切换时：界面立即重排，棋盘按新排版重新计算大小，棋盘数据不变。

---

## 四、"两套排版互不影响"怎么保证（施工要点）

- 界面结构只有一份（不复制两份页面，事件、存档天然一份）。
- 两套样式：
  - 电脑排版 = 现有样式，保持原样，不加改动；
  - 手机排版 = 新增一组样式，**每条规则都以"手机模式标记"开头**，
    如 `html[data-mode=mobile] .layout { ... }`，只在手机模式生效。
- 切换逻辑只做一件事：在页面根元素上挂 `data-mode="desktop"` 或 `data-mode="mobile"`，
  其余全部交给两套样式各自干活。
- 两边作用域完全隔离：改手机样式不会碰电脑样式，反之亦然。

## 五、手机排版长什么样（从上到下）

1. 标题：缩短为"🚢 ShipSolver"。
2. 操作按钮：8 个按钮排两列网格；按钮加大（高度至少 44px），方便手指。
3. 棋盘：占满屏幕宽度，10×10 完整放下、不用左右拖；格子大小按屏宽反算。
4. 图例：默认收成一行"图例 ▸"，点一下展开看完整说明。
5. 信息面板（三个）：
   - 「💡 探测建议」：**默认展开**（核心信息不藏，用户已确认）；
   - 「🚢 进度与状态」：默认收起，点标题展开；
   - 「🔎 探测操作」：默认收起，点标题展开。
   - 手机排版下，把推荐 1 / 2 / 3 的标号直接画在棋盘推荐格上，让预测信息在图上也能看到。
   - 点「开始大探测」后，自动展开「探测操作」面板，方便接着点「确认本次 / 取消本次」。
6. 弹窗（存读档 / 设置 / 帮助）：手机上全屏显示。
7. 页面底部留白：避开手机浏览器的底部工具栏，按钮不被挡住。
8. 「确认整船」按钮：手机排版下放进「探测操作」面板，不再依赖图例区的小按钮。

棋盘格子的手机上显示细则：
- 格子变小后，坐标号（如 1,1）字号同步缩小，保证船格「●」和空格「×」清晰。
- 热力图百分比：手机上放得下才显示数字，放不下就省略（颜色已表达高低），
  具体数字靠「探测建议」面板文字补充（手机上不能悬停，这点和电脑不同）。

导出 / 导入 / 反馈（手机上）：
- 「导出全部」「反馈」在手机浏览器上就是下载一个文件，正常可用；
- 「导入」在手机浏览器上从相册 / 文件里选文件，正常可用。

平板（触屏宽屏）形态：
- 布局用双栏：棋盘在左，信息面板在右（不折叠成单栏）。
- 操作仍是触控（点击=船、长按=空、切换开关），不是鼠标操作。
- 平板竖屏（宽度 ≤ 820px）自动走单栏手机排版，横屏自动走双栏形态。

## 六、手指操作（触控细则）

- 点一下格子 = 标记"船"；再点一下 = 取消。
- 长按约 0.5 秒 = 标记"空"；再长按 = 取消；长按时手机轻微震动一下。
- 控制条放"标船 / 标空"切换开关：复杂局面点一下切到"标空"，之后点格子都写空，不用一直长按。
- 大探测：点 = 暂存船，长按 = 暂存空。
- 长按复制治理：棋盘区域禁用系统长按菜单和文字选择
  （禁止文字选中 + 禁止长按菜单 + 禁止右键菜单），手机上长按格子不会弹复制；
  输入框（如存档名称）不受影响。
- 长按时长固定 0.5 秒，暂不做调节项（用户已确认）。
